隐私政策

最后更新日期：2026年6月

概述

PortAI 是一款桌面应用程序，旨在帮助用户简化 AI API 接口的调用流程并提升使用体验。我们高度重视您的隐私，并致力于以透明的方式运营。

数据收集

PortAI 本身不收集、存储或传输您的个人数据。您的 API Key 等敏感信息仅存储在您的本地设备上，不会被发送至我们或任何第三方服务器。

第三方服务

当您通过 PortAI 调用 API 时，您的请求将直接发送至您所配置的第三方 API 服务提供商。您与这些服务提供商之间的数据交互受其各自隐私政策的约束。PortAI 无法控制也不对第三方服务的数据处理方式承担责任。

用户责任

您所选择接入的 API 服务提供商的隐私和安全实践将直接影响您数据的安全性。我们建议您在接入任何 API 服务前，仔细阅读并了解该服务提供商的隐私政策。

开源透明

PortAI 完全开源，您可以随时审查源代码以验证我们的隐私承诺。我们的代码公开可见，接受社区监督。

联系方式

如有任何隐私相关问题，欢迎通过我们的 GitHub 仓库提交 Issue，我们将尽快回复。

政策更新

本隐私政策可能会不定期更新。更新时将在本页面公布最新版本，建议您定期查阅。
